Every frame is portrait 2:3 — a book cover and a TMDB poster are both that shape, so nothing gets cropped and the stream keeps one row height. Type is not marked. An earlier draft encoded it three redundant ways — a spine rule on the frame, a BOOK / FILM tag at the row head, and the plate line — reasoning that a reader scanning a thousand rows needs to know which is which. They do not. Libraries here are organised by type — Romans, Films, Bandes dessinées — so within any one stream the tag marked a distinction that barely varies, and charged every row for it. Two layers went; the plate line stayed, where a film carries a year and a book does not, and where the poster does not look like a cover.

02

Palette law

Each colour has exactly one job. A colour used for anything else is a bug, not a variation. This is what keeps a two-accent system legible at a thousand items.

Where the yellow goes

An earlier draft spent --imprint on counts, and rendered, that inverted the product's first principle: every loud mark on the home screen served browsing while search — the dominant job — was the quietest element on the page. Placement is not prominence. So yellow now marks the apparatus of finding and acting: the search field, the index letters, the active state, primary actions. Counts are inventory and take a ruled plate. Yellow is how you find and how you act; ink is what you own.

The inverted surface has its own three

--ink-soft on --ink measures about 1.9:1, so the black cover genuinely cannot borrow the paper set. These three exist for the cover alone; using any of them on paper is a bug. They are named for the surface they belong to rather than their brightness — a soft/dim pair would invite the wrong guess, since the body tone is the brighter of the two.

The focus ring is yellow, not red

--imprint already owns the active and selected state, so it owns the focus ring: 3px at 2px offset, flipping to --ink on any element whose own ground is yellow. --out must never be spent here — it means on loan, and a red ring makes every focused element momentarily read as lent. No box-shadow ring either: the no-shadow law is mechanically checkable, and a shadow-shaped outline defeats the check.

Why the stamp's text is black, not red

Red on paper measures roughly 3.9:1 — fine for rules and large bold text, short of the 4.5:1 that small text needs. So the overprint stamp draws its outline in red and sets its caps in ink. Red stays an edge colour, which is exactly the discipline the direction borrowed from a challenger it beat, now enforced by arithmetic rather than taste.

Type scale

Two families, no serif. A book subject reaching for a serif is the association this direction exists to refuse — Série Noire is a sans-and-rules identity. The uppercase rule

Uppercase is for interface labels only — tags, plates, section headers, buttons, all of which are English UI strings. Content titles are never uppercased. Long French titles set in caps lose readability, and this collection's titles are mixed English and French. That single rule is the difference between an imprint and a poster.

Why standalone items carry no plate

There is no item ordinal anywhere in the API — no index, no createdAt, and listing pages are alphabetical behind an opaque token. A per-item sequence number would therefore be invented data wearing the imprint's clothes, and it would renumber itself as you paginate. So the plate carries only real quantities: a library's item count, a collection's member count, a member's order within the series.

An item's genuine catalogue identity is its ISBN or TMDB id, and that already reads in the plate line. Fewer plates on the stream is the right outcome rather than a loss — a number that means something beats a number on everything.

06

One left edge per element

Two edge rules exist — --out for on loan and --shared for sharing — and they can never collide, because they address different scopes. Sharing is a library-level fact in this API; items are never individually shared. So --shared marks library rows and --out marks item rows.

Inside a shared library, an item on loan takes the red edge while the header carries the provenance — declared once, not repeated on every row. On a search row, where the library name genuinely is new information, a shared library is named with an inline green tag, keeping the left edge free. Should the two ever meet on one element, the state the reader can act on wins.

07

The index alphabet is not A–Z

The stream's order is the server's, and the server folds it — NFD, strip combining marks, NFC, lowercase — before the title becomes a sort key. The client reproduces that fold to derive bucket labels and never sorts: localeCompare would disagree with the paginated server order and make the sticky letters non-monotonic.

Because NFD strips only combining marks, Œ and Æ survive it and sort after z; digits and ASCII punctuation sort before a. So the alphabet has a head and a tail beyond the letters.

The count appears only on a closed run. A run closes the instant a different letter appears after it, and at that moment its number is final and correct. The run at the tail of the loaded stream shows no count and no placeholder — the API has no facets or aggregates, so counting only what is loaded would produce a number that grows while you look at it, which is worse than no number. The count is items: standalone entries plus each board's itemCount, counting a board once and ignoring its partial continuation.

Élan folds to e and files under E — correct. Œuvres complètes sits after every A–Z entry, so it gets an honest monumental Œ; showing it as "O" would send a reader to the Os, where it is not.

08

What this system refuses

  • Warm cream or linen grounds, serif display faces, terracotta accents, wooden or shelf materials — the category default, and what v2 already is.
  • Rounded corners, drop shadows, glassmorphism, gradient fills.
  • Cover-art grids as the primary browse structure — artwork is not reliably available.
  • Colour used to distinguish item type; colour is legislated for state alone.
  • Icons standing in for state without words.
  • Any UI implying data the API does not have: genres, tags, ratings, due dates, date sorting, watched status.
  • Read-only mode drawn as a screen of disabled buttons; on a shared library, actions are absent and provenance is declared.

One honest disclosure, and one correction. The titles, counts, dates and summary above are illustrative content authored for this comp, not real catalogue data — replace them with your own before treating any screen as final.

This page previously said no webfont was linked, and that was the most expensive sentence in the document. It loaded whatever grotesque the reader's system supplied, and so — through an unrelated subsetting bug — did the app. Both fell back to the same face, so every reproduction pass agreed and a total failure of the typography survived three slices of review. Matching was mistaken for correct. This comp now loads the same four committed woff2 binaries the client ships, with Google's unicode-ranges verbatim, so it renders in Archivo and Chivo Mono or it visibly fails to. A reproduction target must not share a failure mode with its subject.
